# FH Construction Group homepage redesign

A static, mobile-first homepage concept for FH Construction Group. Open `index.html` directly or serve the repository root with any static server. All CSS, JavaScript and image assets use relative paths, so the site is compatible with GitHub Pages project paths. The demo includes a noindex directive.

## Content and assets

Business details, project references, testimonial and photography are sourced from the existing [FH Construction Group website](https://www.fhconstructiongroup.com/). The FH mark was obtained from the company's profile on The Org. Images are stored locally. External project and contact links lead to the existing company website; no backend or form is simulated.

## GitHub Pages

In repository Settings → Pages, select a branch containing this project and `/ (root)` as the source. Changes on a development branch must first be incorporated into that source branch. Deployment and domain configuration are managed separately from this static project.
